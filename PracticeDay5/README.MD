# 📌 Program Descriptions

## 1. Print Every Element

Print every element present in an array one by one.

**Concepts:** Array, loop, array traversal.

---

## 2. Find Sum

Calculate the sum of all elements present in an array.

**Concepts:** Array, loop, addition.

---

## 3. Find Average

Calculate the average of all elements in an array.

**Concepts:** Sum, array length, division.

---

## 4. Find Maximum

Find the largest element present in an array.

**Concepts:** Array traversal, comparison, conditional statements.

---

## 5. Find Minimum

Find the smallest element present in an array.

**Concepts:** Array traversal, comparison, conditional statements.

---

## 6. Linear Search

Search for a particular target element in an array by checking elements one by one.

**Concepts:** Searching, loop, comparison.

---

## 7. Count Even and Odd Elements

Count how many even and odd numbers are present in an array.

**Concepts:** Modulus operator `%`, conditions, counters.

---

## 8. Reverse Array

Print the elements of an array in reverse order.

**Concepts:** Reverse loop, array indexing, `length`.

---

## 9. Copy Array

Create a copy of the elements of one array into another array.

**Concepts:** Arrays, loops, indexing.

---

## 10. Find Second Largest

Find the second largest element in an array.

**Concepts:** Array traversal, comparison, largest and second-largest values.

---

## 11. Find Second Smallest

Find the second smallest element in an array.

**Concepts:** Array traversal, comparison, smallest and second-smallest values.

---

## 12. Remove Duplicate Characters

Remove repeated characters from a string so that each character appears only once.

**Concepts:** Strings, nested loops, character comparison, `includes()`.

---

## 13. Find Longest Word in a Sentence

Find the longest word from a given sentence.

**Concepts:** Strings, `split()`, loops, comparison, string length.

---

## 14. Check Whether Two Strings Are Anagrams

Check whether two strings contain the same characters with the same frequency.

**Example:**

```text
listen
silent
```

These two strings are anagrams.

**Concepts:** Strings, character comparison, loops, sorting/counting logic.
