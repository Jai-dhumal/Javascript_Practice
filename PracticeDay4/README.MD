JavaScript String Practice

This README contains my JavaScript string practice programs.

The purpose of this practice is to strengthen my understanding of:

Strings

Loops

Conditions

Character comparison

Frequency counting

Nested loops

Basic problem-solving logic

Programs Covered

1. Reverse a String Without reverse()

Reverse a string manually using a loop.

Example:

Input:  "hello"
Output: "olleh"

Main concepts: strings, loops, indexing.

2. Check Palindrome String

Check whether a string reads the same from left to right and right to
left.

Example:

"madam" → Palindrome
"hello" → Not Palindrome

Main concepts: string comparison, reverse logic, loops.

3. Count Vowels

Count how many vowels (a, e, i, o, u) are present in a string.

Example:

Input:  "education"
Output: 5

Main concepts: loops, conditions, character comparison.

4. Count Consonants

Count the consonants in a string by checking characters that are
alphabetic and are not vowels.

Example:

Input:  "hello"
Output: 3

Main concepts: loops, conditions, vowels, character checking.

5. Count Spaces

Count how many space characters are present in a string.

Example:

Input:  "i am a boy"
Output: 3

Main concepts: loops, string indexing, character comparison.

6. Remove Spaces

Create a new string while skipping space characters.

Example:

Input:  "i am a boy"
Output: "iamaboy"

Main concepts: loops, conditions, building a result string.

7. Count One Character's Frequency

Find how many times a particular character occurs in a string.

Example:

String:    "banana"
Character: "a"
Output:    3

Main concepts: loops, frequency counting, conditions.

8. Count Every Character's Frequency

Find the frequency of every character in a string.

Example:

Input: "banana"

Output:
b → 1
a → 3
n → 2

Main concepts: nested loops, frequency counting, character
comparison.

9. Find First Non-Repeating Character

Find the first character that occurs only once in a string.

Example:

Input: "machhindra"
Output: "m"

Main concepts: frequency counting, nested loops, break,
first-occurrence logic.

LeetCode connection: This concept is used in LeetCode 387 - First
Unique Character in a String.

10. Remove Duplicate Characters

Remove repeated characters while keeping the first occurrence.

Example:

Input:  "banana"
Output: "ban"

Main concepts: nested loops, duplicate checking, result strings.

Practice Goal

The main goal is not just to memorize the code.

For every program, understand:

What is the input?

What should the output be?

What does each loop do?

Why is a variable such as count or result required?

How does the value change during every iteration?

Can the same logic be written in Java, C, or C++?

Can the problem be optimized if the basic solution is too slow?
